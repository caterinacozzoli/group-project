# Libby × Libraccio.it

Homepage "Offerte e Outlet" (Figma `2294:25887`) in Next.js 16, con Libby, la libraia digitale (motore locale, senza API).

```bash
npm install
npm run dev          # http://localhost:3000
npm run check:libby  # verifica il motore di Libby
```

- `⌘D` / `Ctrl+D`: anteprima desktop → mobile (393) → tablet (834).
- Decisioni di progetto: `BRIEF.md`. Dati: `data/*.json`. Token: `styles/tokens.css`.
